# Crazy Amy
Script that replace default Kolossos skin with evil Amy Rose. Safe to run, fully local change. <br>
Including almost well animated Amy overlay skin, new sounds and UI details.
#### [[Download file for autoexec folder]](https://github.com/lil2kki-a/My-Outcome-Memories/releases/download/latest/__loadstr_CrazyAmy.lua)
## To execute:
```lua
loadstring(game:HttpGet("https://github.com/lil2kki-a/My-Outcome-Memories/raw/HEAD/CrazyAmy/_main.lua"))()
```
