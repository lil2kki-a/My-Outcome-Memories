# File Based Solo Themes
Swaps default solo round music with your local .mp3 files from executor workspace. Auto-restores original audio if a file got removed, stops tracks on intermission (universal bugfix btw), and lets you set custom ending times. How to use: [YouTube video showcase](https://youtu.be/hG33wFu5j1E)
## To execute:
```lua
loadstring(game:HttpGet("https://github.com/lil2kki-a/My-Outcome-Memories/raw/HEAD/FileBasedSoloThemes/main.lua"))()
```
